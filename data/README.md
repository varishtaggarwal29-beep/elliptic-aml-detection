# Data

This project uses the Elliptic cryptocurrency transaction dataset.

The raw dataset is intentionally not included in this repository because the source files are large and should be obtained from the original dataset provider.

Place the following files in this `data/` directory before running the pipeline:

- `txs_features.csv`
- `txs_classes.csv`
- `txs_edgelist.csv`

The analysis script expects those exact filenames.
